## Description

Sofia came to the helpdesk desk. The shared printer on the Finance floor stopped working for her this morning. Her print jobs sit in the queue with the status "Error - driver is unavailable". Two colleagues can still print to the same printer from their PCs.

## Troubleshooting steps

1. Printed a test page from a colleague's PC to the same printer: it prints, so the printer and network are fine.
2. On Sofia's PC, deleted the stuck jobs and restarted the print spooler (the Windows service that holds print jobs). New jobs get the same driver error.
3. Checked Devices and Printers: the printer shows a generic driver, while the colleagues' PCs show the manufacturer's driver. A Windows update was installed on Sofia's PC last night.
4. Removed the printer from Sofia's PC and re-added it by its IP address instead of from the print server. Windows installs the generic driver again.
