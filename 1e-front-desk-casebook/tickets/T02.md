## Description

Marcus emailed that his branch PC restarts, shows "Working on updates ... 30%" and then rolls the update back with the message "We couldn't complete the updates. Undoing changes." This has repeated three times since Monday night. He can reach the sign-in screen after the rollback and everything else works.

## Troubleshooting steps

1. Checked the update history remotely: one monthly cumulative update shows "Failed to install" with the same error code each time (TODO(verify): Eojin notes the code from the update history in the Decision).

4. Cleared the temporary download cache for updates (stopped the update service, emptied the cache folder, restarted the service). Same failure.
5. Disk cleanup freed about 6 GB. Update not yet retried.
